1. Who we are

MPT Autopilot is open-source software that you run yourself. There is no server operated by us, no hosted account system, and no user database. All processing happens on the machine where you run the app.

2. What data the app handles

  • TikTok OAuth tokens — an access token and refresh token for the TikTok account you connect. They are stored only in your local .env file or in your own CI secret store, and are used solely to call the TikTok API on your behalf.
  • Basic TikTok profile info (user.info.basic) — granted as part of TikTok Login so the app knows which account authorized it. The app reads no profile fields beyond the login exchange and stores no profile data.
  • Video files — the MP4 generated by the app, sent to the TikTok Content Posting API so the draft appears in your inbox. No caption, title, or hashtags are sent to TikTok; you write those yourself in the TikTok app before publishing.
  • Run history — a local posted.json file containing past topics and timestamps, so the app does not repeat itself. It holds no personal data.

3. What we do not do

The app does not collect data about other TikTok users, does not read your followers, comments, messages, or watch history, does not build profiles, does not run analytics or tracking, and does not sell or share any data. This website itself uses no cookies and no analytics.

4. Where data goes

Data leaves your machine only as direct API calls to the services you configured: TikTok (video upload and token refresh), YouTube (video upload), an LLM provider (the topic prompt), and a stock-media provider (footage search). Each of these handles data under its own privacy policy.

5. Retention

Tokens persist until you delete them or revoke access. Generated videos and posted.json stay on your machine until you delete them. Uploaded drafts live in your TikTok account and are governed by TikTok's own retention rules.

6. Your controls

You can revoke the app's access at any time in the TikTok app under Settings and privacy → Security and permissions → Manage app permissions. Revoking immediately invalidates its tokens. You can delete all locally held data by deleting your .env, posted.json, and generated video files. Deleting a draft or posted video inside TikTok removes it from the platform.

7. Children

The app is not directed at anyone under 18 and collects no data from children.
