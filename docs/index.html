MPT Autopilot

A self-hosted desktop/server tool that produces short educational programming videos and delivers them to their own creator's TikTok inbox as drafts.

Terms of Service Privacy Policy Source code

What it does

MPT Autopilot is an open-source Python application run by an individual creator on their own computer or server. On each run it:

  • generates a short-video topic about a programming concept using an LLM;
  • renders a vertical video from stock footage and text-to-speech narration;
  • uploads it to YouTube, and sends the same file to the operator's own TikTok account as a draft in the TikTok inbox.

How TikTok is used

The operator authorizes their own TikTok account once via TikTok Login, granting user.info.basic and video.upload. The app then uses the Content Posting API endpoint /v2/post/publish/inbox/video/init/ to send the rendered video to that account's inbox. Nothing is published automatically — the video stays a draft until the account owner opens the TikTok app, reviews it, writes the final caption, and publishes it manually.

Who it is for

The operator of the app and the owner of the connected TikTok account are the same person. It is not a multi-tenant service and it does not accept sign-ups from third parties.
